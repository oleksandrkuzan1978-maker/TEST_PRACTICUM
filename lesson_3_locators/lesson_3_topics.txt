УРОК 3. ЛОКАТОРЫ, ПРОВЕРКИ ЭЛЕМЕНТОВ И ОРГАНИЗАЦИЯ ТЕСТОВ

Главная тема
Основное внимание уделяется точному поиску элементов страницы и проверке
их состояния. Одновременно изучается разделение тестового кода, адресов
страниц и локаторов, а также обработка ошибки поиска.

Что представлено в модулях
• urls.py — адрес страницы с изображениями вынесен в константу CAT_MEMES.
• locators.py — XPath-выражения вынесены в отдельные переменные: поиск
  элемента по id="bullet" и элемента p по name="Vova".
• find_elements_example.py — фикстура открывает страницу, а два теста
  находят элементы с помощью импортированных локаторов и проверяют
  is_displayed(). Несмотря на название файла, активные тесты используют
  find_element, то есть поиск одного элемента, а не списка.
• exception_example.py — демонстрация try/except NoSuchElementException.
  Выполняется поиск по ID bullet123345; при отсутствии элемента программа
  выводит «Не найден». Это пример обработки исключения, а не pytest-тест
  с assert. Сообщение в консоли само по себе не является проверкой теста.
• homework_3/test_homework_3.py — набор проверок сайта IT Career Hub.
  Проверяются логотип, ссылки меню и переключения языка. Вспомогательные
  функции check_span_links_displayed и check_a_links уменьшают повторение
  XPath-кода. Отдельный сценарий открывает раздел контактов, проверяет URL,
  заголовок и кнопку обратного звонка, затем открывает форму консультации
  и проверяет отображение приглашения.

Какие приёмы поиска изучаются
XPath позволяет искать по атрибутам, вложенным элементам и тексту.
Выражение //img[@alt="IT Career Hub"] использует атрибут alt.
Выражение //a[.//span[normalize-space()='Программы']] ищет ссылку,
внутри которой есть span с заданным текстом. normalize-space убирает
краевые пробелы и сводит последовательности пробельных символов к одному
пробелу. contains используется для поиска по части текста.

Как осваивать материал
1. Сопоставить адрес из urls.py и выражения из locators.py с тестами.
2. Разобрать разницу между нахождением элемента и его видимостью.
3. Проследить обработку отсутствующего элемента в exception_example.py.
4. В домашнем задании сначала изучить короткие проверки меню, затем
   вспомогательные функции и только после этого длинный сценарий контактов.
5. Для каждого assert назвать проверяемое свойство: отображение, адрес
   страницы или наличие текста в выбранном элементе.

Что важно понимать по текущему коду
check_span_links_displayed возвращает bool, а check_a_links возвращает
WebElement. Поэтому во втором случае видимость проверяет вызывающий тест.
find_element при отсутствии совпадения вызывает исключение; он не возвращает
False. Отдельно от этого is_displayed() возвращает признак видимости уже
найденного элемента.
Всплывающая форма консультации здесь проверяется как часть HTML-страницы,
а не как браузерный alert. Переиспользование функций и констант представлено,
но полноценная архитектура Page Object в этих модулях не реализована.

Результат освоения
Учащийся умеет составлять XPath по структуре и тексту HTML, проверять
видимость, вынести повторяемый поиск в функцию и проверять переход
между страницами по URL и содержимому.

Основание описания: фактический код модулей этой папки и её подпапок.
Описание не является отчётом об успешном запуске тестов.
